# Avery Beuth — Portfolio

This is my personal portfolio site: a collection of photography, films, screenplays, and software projects.

## What’s here

- **Photos** — A gallery of photographs.
- **Films** — Short films and video work.
- **Music** — Original music made with JavaScript, with notes on how it is created and links to listen.
- **Scripts** — Screenplays available to read online or download.
- **Code** — Browser tools, games, websites, and desktop applications, with links to try projects or view their source repositories.
